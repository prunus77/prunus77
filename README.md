## Projects

**DynamEye · Smart Navigation Glasses for Low-Vision Users** · [repo](https://github.com/prunus77/DynamEye)  
Flutter companion app for AR navigation glasses. A circular zoom bubble at the center of a live camera feed magnifies what the user is looking at and leaves peripheral vision untouched. On-device object detection with TFLite (SSD MobileNet v2) and WebSocket streaming to the glasses. Covered the full product: user research, tech design, and a market and business case.

**SleePose · Smart Pillow** · [repo](https://github.com/prunus77/Sleepose_Project)  
Pressure-sensing pillow that tracks sleep posture. A piezoresistive sensor woven between conductive threads, read through a voltage divider on a XIAO ESP32-C3. Soft-goods hardware, firmware, and data capture built end to end.

**Edge-Offloaded Gesture Recognition** · [repo](https://github.com/prunus77/Techin515-Lab5)  
A gesture "wand" that classifies on-device and hands off to a Flask + TensorFlow server only when local confidence is low. Trades latency against accuracy without sending every gesture to the cloud.

**Ajaia DocTool · Collaborative Document Editor** · [live demo](https://ajaia-doctool.onrender.com) · [walkthrough](https://youtu.be/wkSiQCH0Enk)  
Lightweight shared-document editor with per-user sharing and .txt/.md import. React + Vite frontend, Express API, Supabase (Postgres), with integration tests against the live schema.

**CEDRA · Economic Independence for Underprivileged Women** · [repo](https://github.com/prunus77/Cedra)  
Next.js site for a nonprofit with Stripe donations, an AI chatbot for personalized guidance, and an accessibility-first multi-page design.

**Fantasy Football AI Agent** · [repo](https://github.com/prunus77/FantasyFootball)  
Retrieval-backed agent that answers lineup questions from public combine, injury, and rushing data, indexed as documents and queried through an interactive LLM loop.

**LinkedIn Content Automation** · [repo](https://github.com/prunus77/Linkedin_Content_Automation)  
No-code pipeline in Make.com that turns content ideas into scheduled LinkedIn posts.
